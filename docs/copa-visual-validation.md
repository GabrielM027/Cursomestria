# Conferência visual do Modo Copa

Em 25 de agosto de 2026, a página inicial foi conferida em prévia local com os dados reais existentes.

O modo normal da página inicial permaneceu íntegro porque ainda não há uma Copa ativa no banco. O cabeçalho, ranking, destaques, partidas e galeria foram carregados normalmente com os dados reais.

O Modo Copa só substitui a abertura quando um administrador criar o rascunho e tocar em **Iniciar Copa**. Nenhuma Copa de demonstração foi criada automaticamente durante a validação.
